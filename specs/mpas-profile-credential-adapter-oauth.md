# MPAS Credential Adapter OAuth Profile

**Status:** Placeholder. Not normative.
**Depends on:** [MCP Authorization specification 2026-07-28](https://modelcontextprotocol.io/specification/2026-07-28/basic/authorization), [MPAS MCP Execution Profile](./mpas-profile-mcp.md)
**Implementation requirements:** [Credential Adapter OAuth](../docs/features/credential-adapter-oauth/spec.md)

This profile will state the MPAS obligations for a Credential Adapter that authenticates to a remote MCP server with standard MCP OAuth. It does not define an OAuth protocol and it does not extend the MCP authorization specification.

The requirements are still being written. Until this profile is normative, implementations follow the feature document above. `docs/features/mcp-oauth/spec.md` remains the record of the draft that already shipped.
